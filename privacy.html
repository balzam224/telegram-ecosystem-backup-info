Telegram Ecosystem Backups

Privacy policy

Last updated: 17 November 2026. This page describes the intended Google Drive integration of this personal utility, which is currently being configured.

Information processed

The utility processes the owner's application database snapshot, application settings and media to create recovery archives. Archives can contain personal information and application credentials. They are encrypted on the application server before upload.

The Google integration will use OAuth authorization tokens and metadata of managed Drive files, including file names, identifiers, sizes and checksums. Tokens will be stored in a protected configuration on the owner's server and used to upload, check and rotate backup archives.

Scope and purpose

The utility will request the drive.file scope to manage files it creates in Google Drive. Google user data will be used only to store, verify and recover the owner's backups. The utility does not include advertising, tracking analytics or sale of Google user data.

Storage and sharing

The owner's server processes the source information. Google Drive will store the encrypted archives and associated file metadata under the owner's account. The archive encryption key will not be uploaded alongside those archives. Operational configuration and secrets are excluded from the public information pages.

The configured retention will be up to three daily archives and one archive before an application update. Rotation will delete only archives managed by this utility, after replacement copies have been checked. The owner may retain separate recovery copies under their own control.

Control and contact

The owner can stop the server job, delete archives through Google Drive, or revoke the application's access through their Google Account connections settings. Revoking access stops future API operations; it does not automatically delete existing archives.

Questions can be directed to the project owner or the support address displayed on Google's consent screen.

These static information pages contain no application analytics or advertising scripts. Their hosting provider may process ordinary web request information under its own policies.
